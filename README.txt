Django Girls Sierra Leone - PHP authentication system

Setup (XAMPP / WAMP / any PHP 7.4+ with pdo_sqlite):
1. Copy this folder into htdocs (e.g. htdocs/authapp).
2. Put the official Django Girls logo at assets/img/django-girls-logo.png
3. Edit includes/config.php with your name, programme, semester and ID.
4. Open http://localhost/authapp/ in a browser.
The database and users table are created automatically on first run.

Quick test without XAMPP:  php -S localhost:8000   (run inside this folder)
